Handle Missing Values

  • Drop columns with too many missing (>70%)

  • Fill missing categorical with Unknown

In [8]:
missing_thresh = 0.7
df = df.loc[:, df.isnull().mean() < missing_thresh]
df.fillna("Unknown", inplace=True)

3. 🏷 Handling Categorical Variables¶

For survey data, most columns are categorical (like gender, country, education). We can:

  • Use Label Encoding for ordinal categories (e.g., education levels).

  • Use Mapping for custom categories.

In [9]:
# Example: Education column
edu_map = {
    "Doctoral degree": 4,
    "Master’s degree": 3,
    "Bachelor’s degree": 2,
    "Some college/university study without earning a bachelor’s degree": 1,
    "No formal education past high school": 0,
    "Unknown": -1
}

df['EducationEncoded'] = df['Q4'].map(edu_map)
